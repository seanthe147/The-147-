---
name: Bookable pool tables
description: Venue rule for retired Pool Table 6 and existing booking records
---

Only Pool Tables 1–5 may be offered for new bookings. Pool Table 6 is retired from the booking system.

**Why:** The user explicitly requested removal of Pool Table 6. Removing it must not delete customer reservations or silently move existing bookings to another table.

**How to apply:** Keep historical bookings readable and cancellable. New bookings, repeats, and reschedules must use a remaining pool table; staff must explicitly select a replacement when editing a retired-table booking. Snooker Table 6 is unaffected.
